# FoodLoop 🌍🍲

FoodLoop is a responsive web application designed to bridge the gap between food surplus providers (restaurants, bakeries, events) and communities or volunteers in need. By facilitating real-time sharing, FoodLoop helps reduce food waste and combat hunger locally.

## ✨ Features
* **Post Surplus Food**: Easily add listings with details like title, quantity, location, and category via an interactive modal form.
* **Live Search & Filters**: Instantly look up specific food items/locations or sort listings by categories (*Bakery, Meals, Produce*).
* **Claim & Remove Mechanism**: Mark food items as claimed or remove them instantly once picked up.
* **Responsive Design**: Fully optimized UI layout for both desktop and mobile devices.
* **Persistent Local Storage**: Built-in client-side state persistence, structured cleanly for future backend integration.

## 🛠️ Tech Stack
* **HTML5** (Semantic layout and structure)
* **CSS3** (Flexbox, media queries, modern UI components)
* **JavaScript (ES6+)** (DOM manipulation, event delegation, `localStorage` API)
